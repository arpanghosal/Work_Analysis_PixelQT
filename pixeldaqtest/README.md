# DAQ Testig Framework

    This repository includes automatic Pixel DAQ testing framework. 

# Setting up

    git clone https://:@gitlab.cern.ch:8443/atlas-pixel/daq/pixeldaqtest.git pixeldaqtest
    cd pixeldaqtest
    source setup.sh

# Run 

    python test_daq.py  --rods ROD_C3_S15 [ROD_C3_S18 ...] [--emulator]

# Help

    python test_daq.py -h to see all the options an their description
